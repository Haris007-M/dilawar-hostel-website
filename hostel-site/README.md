# Hostel Website (Next.js 14 + TypeScript + Tailwind + Framer Motion)

## Run
    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

## Customise (everything is in lib/data.ts)
- Business name, WhatsApp number (digits only, with country code), phone, email
- Hostels, addresses, Google Maps links, room prices and features
- Photos: add files to public/images and match the names in lib/data.ts

## Deploy
Push to GitHub and import into Vercel (free), or run `npm run build && npm start` on any Node host.
